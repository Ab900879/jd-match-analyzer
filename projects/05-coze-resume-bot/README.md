# 05 · 简历优化 AI 助手（Coze）

> **一句话（给非技术面试官）**：调了 50 多轮的简历改写助手。核心是一条边界——可以换个说法，但不许升级动词、不许加没做过的经历。


> **资产性质说明**：这个项目在 Coze 平台上完成，原始对话记录含个人信息，没有随仓库开源。本目录公开的是**可复用的设计资产**：提示词三个版本、知识库结构、验收标准、badcase 分类法。不含虚构的对话数据。

## 设计思路

用 Coze 搭"简历优化助手"：输入简历段落 + 目标岗位方向，输出改写建议。重点不在搭起来（Coze 拖拽即可），而在**调优过程**——50 多轮对话迭代，把答偏和编造的回答逐条修。

## 提示词三个版本（核心差异各一句话）

**v1（最初版）——只说了"你是简历优化助手"**
结果：输出像作文老师，全面点评但不给可替换的句子；偶尔替用户编造没写过的经历。

**v2——加了输出结构约束**
```
按【原句 → 问题 → 改写句】三段输出；改写句必须只使用简历中已有的事实，
不得新增经历、数字或技能；没有把握时输出"证据不足，建议补充：xxx"。
```
结果：编造明显减少，但出现了新问题——过度保守，把"参与运营公众号"这种可优化句也判成证据不足。

**v3（上线版）——加了"可迁移推理"许可**
```
在上一条基础上追加：简历中的经历可以迁移改写（如把"发推文"改写为"内容运营"），
但必须满足：改写句中的每一个事实都能在上文简历中找到出处；动词强度不得升级
（"参与"不可改写成"主导"）。
```
结果：既给出可用的改写句，又不编造。这条边界（迁移可以、升级不行）是 50 多轮迭代里最值钱的一条结论。

## 知识库结构

| 字段 | 用途 |
|---|---|
| 岗位方向 | 产品/运营/技术三分，决定改写的措辞倾向 |
| 动词强度表 | 参与<负责<主导<从零搭建，防止改写时升级动词 |
| 高频 JD 关键词 | 帮助把口语化经历对齐 JD 用语 |
| 反例库 | 收集被判"答偏"的历史输出，作为 few-shot 负例 |

## 验收标准（写在前面的，不是事后补的）

1. 改写句 100% 可在原简历中找到事实出处（抽查）
2. 无新增数字/技能/经历
3. 每条输出都含可直接替换原句的改写句
4. 证据不足时明确说，不硬写

## Badcase 分类法（迭代时逐条归类再修）

- **答偏**：理解错意图 → 修意图识别（补 few-shot）
- **编造**：新增了简历没有的事实 → 收紧"只准用已有事实"
- **过度保守**：能改的不敢改 → 放开"可迁移推理"
- **格式漂移**：不按三段输出 → 输出结构写死 + 温度调低

这个分类法后来直接复用在了项目 01（JD 匹配诊断器）的评测体系里。
