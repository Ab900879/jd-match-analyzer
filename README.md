## 这 8 个东西分别是什么

**01 [JD 匹配诊断器](projects/01-jd-matcher/README.md)** — 网页产品，现在就能用
我自己投实习时说不清简历哪里不对，就做了这个：把岗位要求和简历一起读，逐条标"有依据 / 没依据 / 看不出来"，说"有依据"必须抄出简历原话，抄不出来算它编。编造率压到 1%，12 条样本上合格率从 0 到 67%。样本小是我的短板。

**02 [FAQ 客服 Agent](projects/02-faq-agent/README.md)** — 网页演示，能自己跑测试
客服机器人最怕瞎编政策，所以给了它三条规矩：先查资料、查不到转人工、不许猜。20 条测试第一轮过 17 条，查出两个是我自己判定程序的 bug，改完过 19 条。剩那一条我坚持认为是我的标准写得太理想，留着没改。

**03 [评测与错误归因](projects/03-eval-badcase/README.md)** — 看板，数据是真的
让模型给自己打分等于自己判卷子，所以我用四条规则算分。规则改了三版，同一批回答分数从 83.5 到 92.5 再到 98.8——变的不是模型，是我的尺子。其中两处扣分是我规则写错了。

**04 [需求文档转页面草图](projects/04-prd2wireframe/README.md)** — 命令行工具
需求改一句就得重画原型太烦，所以把草图变成文档的输出：写好的文档跑一条命令出图。200 行，零依赖，14 种元素。

**05 [简历改写助手（Coze）](projects/05-coze-resume-bot/README.md)** — 只有设计，没有代码
调了五十多轮，摸到一条边界：可以换个说法，但不许升级动词、不许加没做过的经历。原始对话有个人信息，没往仓库放。

**06 [豆包/通义/Kimi 拆解](projects/06-competitor-teardown/README.md)** — 只有设计，没有代码
同一套题喂三个产品，90 次测试。结论是"什么任务用哪个"，不是"谁最强"。

**07 [语音面试官](projects/07-voice-interviewer/README.md)** — 命令行工具，能听能判能说
面试没法自己练：对镜子不知道答得够不够，找人模拟没空。这个工具念题、你张嘴答、它判断你答得够不够，不够就追问。结构跟企业的语音 Agent 是同一套——听、判、说。判断用规则不用模型，因为练面试需要可预测；只让模型负责把追问那句说自然。

**08 [外呼质检器](projects/08-outbound-qa/README.md)** — 命令行工具，跑出可直接谈话的报告
外呼质检本质是抽检：一个质检员一天听不了 20 通，坐席一天打 200 通，剩下 95% 没人听过。常见做法是让大模型听一遍打个分，我不信这个——同一通电话今天 78 分明天 82 分，拿去跟坐席谈话第一句就是"凭什么"。所以拆成三层：红线用确定性规则（合规要的是召回，宁可多标让人复核）、流程和沟通用规则加时间戳估算、只有异议和意图这类字面看不出来的才交给模型。5 通样例跑出平均 34 分，3 通踩红线。

## 几句实话

- **代码不是我一行行敲的。** 我干的是定方案、定标准、判断结果对不对，以及出问题时能查出是哪一环坏了。后者比会写代码难。
- **05 和 06 是设计稿，点开看到的不是能跑的东西。**（07 和 08 是命令行工具，报告是现成的，代码要本地跑） 我讲得出过程，但不会假装那是产品。
- **没有真实用户。** 只有我和一个同学用过，这是最该补的一块。
- **有个地方我故意没修。** 03 里还有一条规则不准，修了分数更好看，但那是在拿 20 条样本凑分。

## 想跑一遍的话

需要 Node 18+ 或 Python 3，模型调用走公开的云端接口：

```bash
cd projects/07-voice-interviewer && python main.py   # 语音面试练习（文字模式也能跑）
cd projects/08-outbound-qa && python main.py --all --no-llm   # 外呼质检，不调模型也能跑
cd projects/02-faq-agent && node run-test.mjs    # 20 条 Agent 测试
cd projects/03-eval-badcase && node compare.mjs  # 重算三版规则得分
cd projects/04-prd2wireframe && node prd2wire.mjs examples/prd-jd-matcher.md out.html
```

每个项目目录里都有原始测试数据，JSON 格式，没做过美化。
